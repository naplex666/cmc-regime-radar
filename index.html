How this is built

Core dashboard: no API key needed. It calls the CoinMarketCap keyless public API (https://pro-api.coinmarketcap.com/public-api) once per load — 6 calls total, cached in memory, never re-fetched per keystroke: /v3/fear-and-greed/latest, /v1/altcoin-season-index/latest, /v3/index/cmc100-latest, /v3/index/cmc20-latest, /v1/global-metrics/quotes/latest, /v1/cryptocurrency/listings/latest. The RWA section is keyed (free Basic tier and up): /v5/real-world-assets/assets/list and /v5/real-world-assets/issuers/list — run python3 fetch_rwa.py with CMC_PRO_API_KEY set to unlock it.

Built for the Build with CMC: API Hackathon Round 2 (Plushie), Data and Visualisation track. See README.md for endpoints, limits, and the demo video status.
